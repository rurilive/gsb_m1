# triex2

一个纯标准库的小工具: 用朴素方式维护一个字符串多重集合, 回答前缀相关的问题。

## 现状

`FlatPrefixSet` 内部只有一个字符串列表。插入就是把字符串追加进列表, 删除就是按值
从列表里挪走一个; 前缀判定与前缀计数都用 startswith 逐个字符串比较, 完整单词判定
逐个字符串做相等比较, 按字典序输出靠排序, 最长公共前缀逐列比较全部字符串, 通配符
匹配对每个字符串逐字符朴素匹配。每次查询都要扫全表。

## 问题

查询代价绑死在字符串个数与长度上。字符串一多, 每次前缀判定、前缀计数与通配符匹配
都要把全表看一遍, 明明只跟某个前缀有关, 实现却仍要对每个字符串从头比较; 删除要线性
找位, 删完之后也没有任何结构让后续查询变快。

## 目标

把 `FlatPrefixSet` 从线性扫描扩成以字典树为核心的前缀统计工具: 逐字符插入与删除,
路径上维护经过次数与单词结尾次数, 支持前缀判定、前缀计数、完整单词判定、按前缀取
全部字符串、按字典序输出全部字符串与最长公共前缀, 并可选支持点号通配匹配。删除要
正确维护计数并剪枝。基线那条线性路径保留, 两条路给出的事实要对得上。详见需求描述。
