# sccond

一个只用 Python 标准库的有向图连通性工具包。包内模块 scc.py 提供 Digraph
类，用邻接表保存一张有向图，顶点只要求可哈希且可排序，本模块不解释顶点含义。

## 现状

Digraph 支持加顶点、加边、查邻居、查出度，以及单点可达与两两互达判断。
可达的做法很朴素：每次都从起点重新做一次深度优先搜索，只回答这一次询问，
不缓存任何中间结果。凡是涉及互达或同分量的判断，都要正反各跑一遍遍历。

求强连通分量的办法是：对每个尚未归类的顶点，与其余每个顶点逐一做一次互达
判断，把与之互达的收进同一块。缩点成有向无环图后，求拓扑序、求最长链、
求源分量与汇分量，以及判断整图是否强连通、求分量之间的可达关系、求一个
顶点能到达的最大分量，也全都建立在反复的可达搜索之上。

## 问题

每问一对顶点就要跑两遍遍历，问遍所有点对时整体代价迅速膨胀，平方再乘搜索
量级；更根本的是，当前代码里没有分量这个独立实体，也拿不出三路可互相印证
的分量划分，调用方无法在多种分解口径之间对账，只能靠反复的两两判断去近似，
既慢又散。

## 目标

把 Digraph 从两两可达判断扩成以强连通分量与缩点为核心的图算法工具：一次
深度优先加栈分解出全部分量（时间戳与栈口径）；正图与反图两趟深度优先分解；
以及迭代而非递归的实现以避免深链爆栈。三路对同一批图给出的分量划分逐项
一致，分量编号按最小顶点升序固定，三路互不调用。再基于缩点图求拓扑序、
最长链、源分量与汇分量，并接上整图强连通判断、分量间可达与最大可达分量
顶点数三项独立能力，都要与逐对可达的朴素口径一致。分解代价要与边数和点数
线性，并暴露朴素逐对搜索次数与一趟分解访问次数的规模对照。空图、单点、
无边的多点、自环、双向边、链状图、多个分量、整图强连通、DAG 本身、含重边
等边界都要有确定行为。固定图重复分解结果完全一致，异常统一继承基类。
