# movavg

一个统计移动速率与平均的小工具，纯标准库，无外部依赖。

## 现状

movavg/meter.py 里只有一个 Meter，做的是朴素全量平均：

- record(value)：把样本累加进总量与计数
- mean()：总量除以个数，没有样本时返回 0.0
- count() / total()：累计的样本数与求和，样本永不被淘汰
- reset()：清零，回到刚建立时的状态

它不看时间，没有窗口，没有分位，也没有平滑。样本一直留在内存里，
时间越久种得越多，拿不出「最近这段时间每秒多少事件」这类量。

## 问题

全量平均把所有历史样本一视同仁，无法反映近期的速率变化；没有时间
窗口，老样本永不淘汰，内存随样本数无界增长；拿不出分位数，也没有
对速率做平滑的手段；没有统一的快照与重置语义，调用方无法在某一刻
一次性取走全部指标。
