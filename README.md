# aclib

一个纯标准库的多模式字典匹配小工具包。当前只提供朴素字典 BruteDict。

## 现状

BruteDict 内部按加入顺序保存一组模式串,add 负责加入模式,
count_occurrences、first_match、matches_in 分别给出各模式的出现次数、
最早出现位置与全部出现位置。所有查询都对每个模式单独在文本上扫一遍。

## 问题

逐个模式分别扫描文本,模式一多就重复劳动,同一段文本被反复走过,
而且一次扫描无法同时命中全部模式,也拿不到某个位置上命中的模式集合。

## 目标

把 BruteDict 扩成以多模式自动机为核心的字典匹配工具:一次扫描文本
同时命中全部模式,并暴露可读的失配结构、命中集合与扫描字符计数,
同时保留原有逐个模式的扫描路径,两者在事实层面必须一致。
