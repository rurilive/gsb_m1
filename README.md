# ttlidx

纯标准库的内存索引，无外部依赖。应用里常要按主键快速查到一条记录，
ttlidx 就是管这层按键存取的索引。

## 现状

ttlidx/index.py 提供一张永不过期的字典索引 DictIndex：

- set(key, fields)：写入或覆盖一条，同名主键覆盖时位置不变，字段按值拷贝存下
- get(key)：按键取回字段的一份拷贝，键不存在返回 None，并记一次命中或未命中
- delete(key)：按键删除，删到返回 True，本来就不在返回 False
- keys：按写入顺序给出全部主键；contains：判断键是否存在
- stats：live / hits / misses 计数快照

现有实现只有永不过期这一条路：写进去的条目一直留着，没有过期时刻也没有时钟，
取不回来的条目只能靠人手删；没有能按字段反查的二级索引；多条字段的更新不是原子的，
改到一半失败就留下半新半旧的一条；也无法问出哪些条目即将过期；并发清理没有保护，
两条清理路径可能对同一条重复动手。

## 问题

把现有这套朴素索引扩成生产可用的带 TTL 索引，缺的东西集中在几处：没有过期时刻，
条目一律永不过期；没有注入时钟，过期与否无法在测试里稳定复现；惰性过期与主动清理
两条路都要有，且口径要一致；过期条目要同步从所有索引里移除，不能留下悬挂的倒排项；
字段更新要么整体生效要么整体不动，失败要能回滚且索引保持一致；要能按时间窗扫出
即将过期的条目用于预热或告警，结果有序；并发下的惰性判定与主动清理不能重复清理、
也不能误删未过期项；非正的 ttl 要立刻拒绝，重复 key 的语义要明确。
