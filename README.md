# treap

用一个 Python 列表维护一段整数序列的小工具，纯标准库，无外部依赖。

## 现状

treap/seq.py 只有一个朴素实现，Seq 直接在底层列表上操作：

- get(pos)：取第 pos 个元素，直接下标
- insert(pos, value)：取前段、接上单个元素、再接后段，整段拼回
- remove(pos)：取前段与后段，跳过被删位置，整段拼回
- sum(lo, hi)：对截出的子列表逐个累加
- min(lo, hi) / max(lo, hi)：对截出的子列表逐个比较
- kth(lo, hi, k)：截出该段自行排序后按下标取第 k 小
- rank(pos)：取该位置的值，再从头逐个数比它小的个数
- to_list() / len()：浅拷贝当前整段与当前长度

没有树、没有分层结构，每次操作都整段拷贝或逐元素重排，序列一长
就退化成线性甚至平方。

## 问题

重复的按位置插删与区间查询每次都从头重扫，压不下代价；没有一条
以平衡子树承载序列、把单次代价压到对数级的路径；也没有一条独立
的朴素路径与树路径逐项对照。
