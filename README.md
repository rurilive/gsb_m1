# shardstore

缓存层的内存键值表，纯标准库，分片集合在建表时定死。

- `shardstore/store.py`：`ShardedKV` 的 `put()` / `get()` / `delete()` 读写，`shard_of()` 查键落在哪片，`keys_in()` / `size()` / `distribution()` / `total()` 看分布
- `tests/test_store.py`：行为基线
- `demo.py`：读写与分布演示

## 实现说明
1. 路由：每片是「哈希模 N 落桶 + 高位掩码」描述子；分裂只给老片加一个哈希位收窄一半，新片接走另一半，别片描述子不变，`shard_of()` 永不全量重排。
2. 搬移期读：属主是新片的键先查新片，查不到回退老片；属主是老片的键只查老片，不会把还没搬的键判成没有。
3. 搬移期写：搬走那一半的键新片、老片双写，删除也两边一起删；老片全量副本保留到提交，回退不用补数据。
4. 进度：`begin_split()` 固化起点快照，`migrate_batch()` 按快照游标批量拷贝，`split_progress()` 给已扫/待扫/已搬计数，每批落盘一次。
5. 断点续传：状态文件（原子写+rename）存路由描述子、快照与游标；重启构造时读回，搬过的不重搬，游标之后的写入由提交前锁内最终追平兜底。
6. 原子切换：提交先对账（该搬的两边同值、新片无孤儿），再把已提交拓扑原子落盘，最后换内存路由指针并清老片副本，要么全成、重启即按新拓扑，要么回退恢复旧掩码丢新片。
