# geox

一个只用 Python 标准库的平面计算几何工具包。包内模块 geom.py 提供 PlanarGeom 类，
围绕平面点集与线段做四件最基础的事：convex_hull 求凸包，closest_pair 求最近点对，
segments_intersect 判断两条线段是否相交，point_in_polygon 判断点是否落在多边形内部。

## 现状

四件事一律靠朴素做法：凸包逐个点判断谁在谁的外侧，最近点对两两配对全部比一遍，
线段相交写成参数方程解一次方程组，点在多边形内用逐边射线法数穿越次数。规模小时
直观可靠，结果一眼能看穿。

## 问题

朴素做法在规模一大就退化：最近点对要平方级配对，凸包要平方级比较，每次查询都像
把全部数据重新翻一遍。实现既没有把规模压下来的手段，也没有任何计数能说明一条更
聪明的做法到底省了多少，更谈不上旋转卡壳直径、面积周长、半平面交这些进阶能力。

## 目标

把 PlanarGeom 从朴素几何扩成一套高效计算几何工具集：最近点对改成分治或扫描线，
凸包改成葛立恒扫描或安德鲁单调链，线段相交与点在多边形内补全共线、重合、边界等
退化情形；再补旋转卡壳凸包直径、凸多边形面积周长与半平面交；暴露比较次数证明它
明显小于两两比较；覆盖锐角退化、共线、重合点、空点集、单点、全共线点集等边界；
固定点集重复跑两次结果一致，不依赖模块级可变状态；异常统一继承 GeomError 基类并
快速失败；基线那条朴素路径一条都不许删，两条路对同一批数据的事实必须逐项对上。
