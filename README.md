# invx

一个只用 Python 标准库的小仓库，提供整数序列上的逆序统计工具集。

## 现状

- 包名 `invx`，核心类 `Values`，位于 `invx/inv.py`。
- 逆序对、正序对、相等对一律用双重循环枚举所有下标对，逐一比较后累加。
- 三种计数互不重叠，之和等于下标对总数，等于长度选二。
- `has_duplicates` 与 `distinct_count` 先整体排序，再从头到尾线性扫一遍。
- `kth_smallest` 整体排序后按下标取，空序列抛 `EmptySequenceError`，越界抛 `SequenceTooShortError`。
- `rank_of` 返回严格小于给定值的元素个数。
- 非法输入（非可迭代、非整数、布尔值）一律抛 `InvalidInputError`。
- 所有自定义异常继承自 `InversionError`。

## 问题

下标对的数量随元素个数平方增长，规模一大就比较平方那么多次；
重复判定、不同取值计数与按排名取值都是先付一次排序的全额代价、
再线性扫，前面的排序结果没有为逆序统计留下任何可复用的中间结构，
两件事各干各的。

## 目标

把核心扩成以归并与树状数组为核心的逆序统计工具集：一条路用归并分治，
在排序过程中统计跨越两半的逆序对，并暴露递归层数；另一条路先把序列
离散化成排名，再用树状数组按排名做前缀统计，并暴露访问计数；两条路
对同一批数据给出的逆序对、正序对与相等对必须逐项一致。统计口径保持
严格大于、严格小于、恰好相等三分，三者之和等于下标对总数。覆盖单调
递降、单调递增、全相等、含重复元素等边界，并可补逆序对奇偶判定或每个
元素左右两侧更大更小的计数。原先那套双重循环枚举与排序扫描保留下来
做对照。
