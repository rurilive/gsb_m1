# kdtree

静态点集上的范围查询与最近邻查询，纯标准库，无外部依赖。工程里常要在
一批整数坐标的 k 维点上按轴对齐矩形取点、或找离查询点最近的那个点，
kdtree 就是负责这层检索的库。

## 现状

kdtree/scan.py 只有最朴素的一层实现，全是裸函数：

- assert_points(points)：校验点集，各点非空、维度一致、坐标为整数
- assert_box(box, dim)：校验矩形，两个 k 维边界，下界不大于上界
- inf_norm_sq(p, q)：两点各坐标差平方之和，整数
- points_in_box(points, box)：逐点判定是否落在闭矩形内，返回命中下标升序
- nearest(points, query)：逐点算平方欧氏距离取最小，并列取下标最小

范围查询与最近邻查询都是线性扫描，规模一大就慢；没有按维度划分的树结构，
也没有任何剪枝；没有条独立做法可拿来逐项对照；异常也还没有统一的基类。

## 问题

把现有这套线性扫描扩成能应付大规模与各种边界的实现，缺的东西集中在几处：
没有按维度交替取中位数递归建起来的 k 维树；范围查询没有按包围盒剪枝；
最近邻没有按当前最优与分割面距离剪枝；没有一条独立做法在固定输入上逐项对照。

## 目标

见任务描述。约束：

- 现有行为与 tests/test_scan.py 基线一致（基线一个字不改）

- 结果确定性，范围查询与最近邻的新老两条路径逐项一致
