# resvoir

纯标准库的流式抽样器雏形，无外部依赖，Python 3.10+。

## 现状

resvoir/buffer.py 提供一个 KeepAll：

- add：把流入的元素连权重与标签一起记录下来，权重必须为正数
- seen、items、weights：累计流入计数、按流入顺序取回全部元素与权重
- sample：唯一的取样本入口，朴素实现里样本就是留住的全部元素
- total_weight、mean：权重之和与全量加权均值
- quantile：在留住的全部元素上精确取分位
- by_label：按标签把留住的元素分组
- clear、is_bounded：清空留住的元素与计数；朴素实现内存无界，标记恒为假

抽样只有全量保留这一条路，流入多少就留多少，样本等于全体，均值与分位
都在全量数据上精确算；没有固定容量，没有随机替换，没有加权选样，没有
分层，也没有把两个样本并起来的办法。

## 问题

元素一多，留住的元素就跟着线性膨胀，内存没有上界；想只要一小撮代表，
现在的实现给不出，只能先全量收下再自己截；权重只在算加权均值时用得上，
抽样本身完全无视权重，重权元素并不会更容易被选进样本；按业务标签分组
以后，小群体很容易被大群体淹没，样本里根本看不见；样本小的时候统计量
的偏差多大也没有任何交代；两份分别采出来的样本想拼成一份，现在也没有
等价合并的口径。

## 目标

在当前基础上补出固定内存的均匀蓄水池抽样、加权抽样、分层抽样、样本
统计与样本合并，见任务描述。约束：

- 现有行为与 tests/test_buffer.py 基线保持一致（基线一个字不改）
- 纯标准库，随机源可用固定种子复现
- 无论流入多少元素，内存占用固定为 O(k)（k 为容量），统计可证
- k 非正 fail fast；空流样本为空；固定种子下样本逐项可复现

```bash
python3 demo.py
python3 -m unittest discover -s tests -v
```
