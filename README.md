# persistx

一个纯标准库的 Python 序列库。

## 现状

当前只有最朴素的实现。序列整体存在一个 Python 列表里（`MutList`），
追加就是尾部添加，弹出就是尾部删除，设值与取值按下标直接改同一个列表，
`snapshot` 返回整份浅拷贝。任何一次修改都就地改这同一个列表，旧的快照
只能靠事先手动拷贝，版本之间没有任何共享。

基线行为由 `tests/test_seq.py` 锁定，包含初始化、入尾、弹尾、按位取值设值、
快照独立性、长度以及越界错误等语义。

## 问题

就地修改意味着想保留历史就必须整份复制；序列一长，每次改动都付出与长度
成正比的代价，且各版本之间毫无结构共享，无法在历史版本上继续推进。

## 目标（见任务描述）

把 `persistx` 从朴素可变列表扩成以持久化数据结构（路径复制或结构共享）
为核心的版本化序列，公开能力与可断言口径以任务描述为准。目标实现不在本
基线内，`demo.py` 第二段与本文末尾的说明均为占位。
