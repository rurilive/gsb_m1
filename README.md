# topodag

有向无环图拓扑排序的朴素实现雏形，纯标准库，无外部依赖。

## 现状

`topodag/graph.py` 提供 `DirectedGraph`，只有一条最直白的路：

- `node_count()`、`edge_count()`、`nodes()`、`edges()`：规模与原始边表
- `successors(u)`：某点的直接后继列表
- `in_degrees()`：每个点的入度
- `topological_order()`：反复在整张图里从头线性扫描找当前入度为零的点里编号
  最小的那个，取走一个输入结果，再沿着它出去的每条边把另一端的剩余入度减一；
  有环时某一轮找不到零入度点即返回 `None`
- `has_cycle()`：拓扑序是否为 `None`
- `reset_counters()`、`counters()`：扫描结点次数与重走边次数的规模计数

现状全部走朴素口径：每取走一个点就把全部结点重扫一遍，每一轮还要把它出去的边
重走一遍，轮数与每轮重扫的结点数、边数双双上去，代价随点数与边数平方级增长。
口径直白、结果确定，但与编号挂钩的取点方式在规模一大时退化明显，也没有任何关于
关键路径的能力。异常基类是 `Erro`，建图参数非法抛 `InvalidGraphError`，查询越界
或未登记结点抛 `NodeNotFoundError`。

## 问题

没有入度表加队列的一次线性拓扑排序，取点只能一轮轮回头把整张图重扫；并列可选点
之间只有编号最小这一条隐含口径，缺少一条独立于队列的深度优先后序口径来做交叉核
对；更没有关键路径（最长路）与最短工期，也没有把环上点序列拿出来精细定位的能力。
