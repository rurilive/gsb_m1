# manacher

一个只用 Python 标准库的回文统计小包。

## 现状

核心是 pal 模块里的 BruteStats，内部持有一份字符串。判断某段是不是回文，就逐字符从两端往中间比；求最长回文，就枚举每一个子串逐个判断取最长；数回文子串总数，也把每一个子串都判一遍；本质不同回文的种数与某个回文的出现次数，同样靠枚举子串去数；对给定中心求最长回文半径，也向两边暴力扩展。

## 问题

这套做法整体是平方级的。文本一长，枚举子串的判断次数按长度平方增长，很快撑不住；中间结果完全没法复用，每一段都要从头再比一遍。

## 目标

在保住既有对外行为的前提下，把 BruteStats 改造成以马拉车算法为核心的统计工具，仍然只用标准库，由回文半径与最右回文边界一趟线性求出每个中心的回文半径，据此给出最长回文子串长度、回文子串总数、本质不同回文种数、每个回文出现次数与以每个位置结尾的最长回文长度；并保留一条独立的中心扩展暴力路径做对照，两条路对同一批数据逐项一致。

## 运行

在仓库目录下：

```
python3 demo.py
python3 -m unittest discover -s tests
```
