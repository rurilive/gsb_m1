# seekr

纯标准库的内存全文检索雏形，无外部依赖。

## 现状

seekr/scan.py 提供一个 Corpus：

- add、remove：按文档名加入或删除一篇文档，文档名重复报错、不存在报错
- doc_ids、text：按加入顺序取回文档名、按文档名取回原文
- search：唯一的检索入口，逐篇文档扫一遍，命中原文字串包含给定子串的文档
- count：统计子串在所有文档原文里出现的不重叠次数

检索只有子串包含这一条路，大小写敏感，不看词边界，没有分词、没有倒排、
没有位置，也没有任何排序依据。

## 问题

每查一个词都要把每篇文档的原文从头扫到尾，多词条件只能自己写循环去拼，
词序、邻近这类要求表达不出来；命中结果按加入顺序返回，相关的一篇与
不相关的一篇排在同一个位置；删掉文档之后，除了原文，没有任何索引结构
需要跟着清理，因为现在根本没有索引。

## 目标

在当前基础上补出分词与倒排、布尔检索、短语检索、评分排序、命中词位置
与增删一致性，见任务描述。约束：

- 现有行为与 tests/test_scan.py 基线保持一致（基线一个字不改）
- 纯标准库
- 布尔组合的结果必须与朴素集合运算一致，短语必须按位置相邻匹配

