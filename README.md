# deltafy

纯标准库的文本差分小包，无外部依赖。给两段文本比对差异、把差异当成补丁
传输，再把补丁应用回去并回滚。

## 现状

deltafy/compare.py 提供最简单的逐行比较器 LineDiff：

- operations：两段文本按行切开，从第一行起逐行比对，相同位置内容不同记一条
  替换，相同位置内容一致记一条相同，line_no 从 1 开始
- changed_count：被记成替换的行数
- same_count：被记成相同的行数
- deltafy/__init__.py 只导出 LineDiff

没有最长公共子序列，没有增删对齐，没有补丁，没有把改动应用回去的能力，
也没有三方合并。

## 目标（见任务描述）

把 deltafy 从逐行比较扩成完整差分引擎：基于最长公共子序列产出增、删、相等
三类操作的最小编辑脚本，且在不唯一的最短解里取一个确定解；把脚本序列化成带
上下文行数、越界上下文裁到边界的可传输补丁；把补丁应用到旧文本得到新文本，
并能反向回滚，一处不匹配就 fail fast 且不留下半个结果；对同一对文本生成补丁
再应用等于目标，对相同补丁重复应用按明确策略处理；给定基础与两侧改动做三方
合并，非冲突改动自动合入，冲突处标出冲突区间并能报告冲突数量，纯插入与纯删除
不误判为冲突。全部仍在 deltafy 里，纯标准库，异常继承 DiffError 基类。约束：

- 现有行为与 tests/test_compare.py 基线保持一致（基线一个字不改）
- 新行为另开 tests/test_diff.py，用固定文本断言
- 纯标准库，不引第三方
