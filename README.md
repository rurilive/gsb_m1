# hullx

一个只用 Python 标准库的平面点集凸包工具包。包内模块 hull.py 提供 HullKit 类，
围绕平面点集做四件最基础的事：convex_hull 求凸包，diameter 求最远点对，
min_bounding_rect 求面积最小的外接矩形，width 求点集宽度。

## 现状

四件事一律靠朴素做法：凸包枚举每一对点，看其余点是否都落在它的一侧，据此判定
这条有向直线是不是边界，再把边界串成环、把落在同一条边内部的共线点去掉；
直径在凸包顶点上两两配对全部比一遍；最小外接矩形把全部顶点对当成候选朝向，
逐个把凸包投影到该朝向下求轴对齐包围盒，取面积最小者；宽度取自最小外接矩形
里最小的法向跨度。规模小时直观可靠，结果一眼能看穿。

## 问题

朴素做法在规模一大就退化：凸包要按点对逐个判定，点一对就是立方量级；直径要
平方级配对；最小外接矩形要按顶点对枚举朝向，每个朝向再把全部顶点投影一遍。
实现既没有把规模压下来的手段，也没有任何计数能说明一条更聪明的做法到底省了
多少，更谈不上旋转卡壳这类沿凸包一圈推过去的近线性口径。

## 目标

把 HullKit 从朴素几何扩成一套高效的凸包工具集：凸包改成按极角排序或单调链的
近线性构造，直径、宽度与最小外接矩形改成旋转卡壳的近线性口径；新老两路对同一
批点集的事实逐项一致，并暴露两者在点数与卡壳步数上的差距；覆盖共线点、重复点、
点数不足、全部共线退化、凸包退化成一个点或一条线段等边界；固定输入重复跑结果
一致且不依赖模块级可变状态；异常统一继承 HullErro 基类并快速失败；基线那条朴素
路径一条都不许删。

    python3 demo.py
    python3 -m unittest discover -s tests
