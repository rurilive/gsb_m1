# meldset

一个只用 Python 标准库的集合族合并小工具。包内模块 merge.py 提供 HeapMerge 类，
维护若干整数字典，每个字典代表一个集合，键是整数元素，值是元素到某属性的映射。

## 现状

HeapMerge 支持新建与删除集合、合并两个集合、查询集合大小、查询某元素属性、
修改某元素属性。合并的做法很朴素：新建一个空集合，把参与合并的全部元素逐个
搬迁进去。相交元素以被合并一侧的属性为准，旧句柄随后作废。

## 问题

每次合并都要把参与的两侧整体重写一遍，哪怕其中一侧很小，也要连同另一侧的大
集合一起搬迁。元素越多、反复合并的次数越多，这种整体搬迁的代价就越突出，而
当前实现既没有搬迁代价的意识，也没有任何度量手段。

## 目标

把 HeapMerge 扩成以小并大启发式合并为核心的集合族工具：合并时只搬迁较小一侧，
总搬迁代价按元素个数量级下降；暴露元素搬迁总次数以便度量差距；按大小与按秩
两种启发式都要给出等价结果；支持整体删除集合并对已删句柄快速失败；与并查集口径
衔接；覆盖空集、单元素、自合并、反复合并、合并到已删集合等边界；保证固定操作
序列重复运行结果一致。

## 运行

    python3 demo.py
    python3 -m unittest discover -s tests

（实现后补，10 行以内）
