# twosat

一个纯标准库的小工具: 判断一组二文字子句构成的公式是否可满足, 并给出一组
可行赋值。

## 现状

`solve` 只有一条路径, 就是对每个布尔变量枚举真与假, 一共二的变量数次方种
组合, 每一种都拿全部子句从头到尾验证一遍。子句少、变量少时够用。

## 问题

求解代价绑死在变量个数上。变量一多, 枚举的组合数就指数级膨胀, 哪怕公式里
只有寥寥几条子句也要把所有组合试一遍。上层想做批量判定与解计数时, 这种
慢法根本撑不住规模。

## 目标

把求解从枚举扩成基于蕴含图的判定工具: 每条二文字子句拆成两条蕴含边建图,
求强连通分量, 同一变量与其取反落在同一分量即不可满足, 否则按强连通分量
拓扑序的逆序给出一组可行赋值; 另起一条独立做法用枚举赋值在固定输入上逐项
一致。基线那条枚举路径保留, 两条路给出的事实要对得上。详见需求描述。

## 运行

```
python3 demo.py
python3 -m unittest discover -s tests
```

（实现后补，10 行以内）
