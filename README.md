# lagrange

一个纯标准库的插值与多项式运算工具箱，无外部依赖。做数值拟合、离散序列求和、
多项式恒等变形的脚本里，总会碰到一串点要求过它们的多项式取值，lagrange 就是
干这件事的那一层。

## 现状

- `lagrange/interp.py`：给定若干插值点，先铺出范德蒙德方程组，用朴素高斯消元
  解出多项式系数，再逐项累乘代入求某点的值；整数、分数或浮点都按分数精确表示，
  不做浮点近似。
- `naive_fit_coefficients`：铺范德蒙德行再调朴素消元解系数，点数一大方程组就胀。
- `solve_linear_system`：最直白的高斯消元，按当前行序选主元，主元为零即报错。
- `naive_eval`、`naive_value_at`：逐项累乘求值，第 i 项把 x 自乘 i 次再乘系数。
- `naive_mul`：多项式乘法两两双重循环再按次数累加。
- `naive_power_sum`：连续整点幂和从一到 n 逐项枚举。
- `naive_solve_cost`、`naive_eval_cost`：露出解方程与逐项求值的规模对照。
- `lagrange/LagrangeError`：所有可诊断错误的基类，带 `message`、`position`
  与 `data`。

## 问题

现在求过这些点的多项式在某点的取值只有一条路，先解方程组求系数再代入；多项式
乘法是双重循环；求值逐项累乘；整数幂和靠逐项枚举。结果都对，可点数或次数一高，
解方程组的量级与逐项求值的量级就压得跑不动；插值点重复、空点集这些边界混在
各处，没定下统一的口径；给出的取值也没有第二条互不相干的路径来互相印证。
