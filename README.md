# vcbox

纯标准库的逻辑时钟小包，无外部依赖。

## 现状

vcbox/clock.py 只提供最朴素的整数时钟：

- Clock(value=0)：一个整数计数，默认从 0 起
- tick()：推进一个本地事件，计数加一并返回
- value：读当前计数
- 两个时钟只比大小，等于、小于、小于等于按数值判定
- 初值必须是整数且非负，否则抛 TypeError 或 ValueError
- 没有向量、没有偏序、没有合并，也没有并发判定

tests/test_clock.py 把上述基线行为锁住，一字不改。

## 目标（见任务描述）

在现有 Clock 之上把 vcbox 扩成向量时钟与偏序：每个进程一份按进程 id 索引
的计数向量，本地事件自增本进程分量，发送前记录、接收时按分量取最大再自增；
任意两向量能判定相等、严格小于、严格大于、并发四种互斥且完备的关系；长链、
分叉汇合与相互独立等常见值环下判定与手工推演一致；两份向量按分量取最大做
合并并满足幂等、交换律、结合律；单进程退化情形下与整数时钟的序一致；缺分量
按零处理，未知进程分量或非法进程 id fail fast。全部仍在 vcbox 包内，纯标准库。
