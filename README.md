# lisx

最长上升子序列工具包，纯标准库，无外部依赖。

## 现状

lisx/lis.py 提供 LisKit：

- length(seq, mode)：严格上升与非下降两种口径的最长上升子序列长度，空序列返回零，单元素返回一
- count(seq, mode)：上升子序列的个数，按下标集计，含全部长度，值相同下标不同算不同，空序列计一
- rebuild(seq, mode)：重建一条最长上升子序列，返回下标序列与取值序列，方案只需合法
- comparisons：本次调用长度的两两比较次数
- rebuild_comparisons：本次调用重建方案的比较次数
- LisErro：异常基类，下分 SeqErro 与 ModeErro

## 问题

长度靠每个位置向前枚举全部更小的位置累加，序列一长就是平方量级；个数靠位掩码
枚举全部子序列，规模稍大就指数级退化；重建也逐位置往回扫。三条路都慢，也拿不
出任何计数说明更聪明的做法省了多少。调用方看到长度却不知道具体方案，看到方案又
没有独立的个数口径互相印证，三条路之间没有任何核验，边界情形更无从对照。
