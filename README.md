# bloomx

埋点去重用的布隆过滤器，纯标准库，容量在建实例时定死。

- `bloomx/filter.py`：`BloomFilter.add()` / `in bf` / `len(bf)` / `to_bytes()` / `from_bytes()`，按容量与目标假阳性率算位数组大小
- `tests/test_filter.py`：行为基线
- `demo.py`：写入与查询演示

## 实现说明

- 片管理：`ShardBloomFilter`（`bloomx/shard.py`）持有一个片列表，`add_shard()` 在线追加新片，旧片位数组冻结不动，写入只进最新片，添片全程不停机
- 跨片查询：`in` 对片列表做快照后逐片查询，任一片命中即命中，漏一片就会假阴性，所以必须全查
- 在线添片并发安全：锁只保护片列表引用，置位操作不持锁；添片只换引用、不改旧片，添片期间的写入完整落旧片或新片，不丢
- 老数据：`from_bytes()` 自动识别老 BLM1 单实例格式，整体包成唯一一片，容量与目标率从位数和哈希数反推，历史数据原样可读
- 新持久化：BLM2 头 + 逐片（容量 + BLM1 片体），重启后整片列表原样恢复
- 假阳性率：对外只给一个整体值，按 `1 - ∏(1 - 片率)` 求并；片率由该片 k、容量与实际写入量推导，空片贡献为 0
- 内存兜底：`max_shards` 限制片数（默认 16），到顶再 `add_shard()` 抛 `ShardCapacityError`，拒绝继续吃内存
