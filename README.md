# sketchlib

纯标准库的频次统计小工具包，无外部依赖。埋点和日志管线需要在只看一遍数据、
不保存全部键的前提下估出各键大概出现了多少次，这个包就是为这类场景准备的。

## 现状

- `sketchlib/sketch.py`：`ExactCounter`，用一个普通字典逐键记录真实计数。
  `add(key)` 计数加一，`count(key)` 返回精确计数（键不存在返回零），
  `total()` 返回总计数，`distinct()` 返回不同键数，`top(k)` 按计数降序取前 k，
  平局时按插入序排。异常统一用 `SketchError`。
- 所有结果都精确，代价是内存随不同键的数量线性增长。

## 问题

海量不同键一来，精确字典就存不下，内存随基数一路涨到撑爆；
可业务其实只关心高频元素和大致频次，不需要每个键都存一份精确计数。
