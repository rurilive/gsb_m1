# halfplane

平面半平面交，纯标准库，无外部依赖。工程里常要在一个凸区域内做裁剪、取可行域，
halfplane 就是负责把若干半平面求成交多边形的那一层。

## 现状

halfplane/hpi.py 用有向直线表示半平面，提供最朴素的求交：

- HalfPlane(a, b)：直线 a 到 b 的左侧半平面，含边界，两点重合抛 ValueError
- contains(p)：点是否落在半平面内，用整数叉积判定
- line_intersection(h1, h2)：两条有向直线的交点，平行返回 None
- intersect(halfplanes)：枚举每一对边界直线的交点，保留落在所有半平面内的点，
  再求凸包并算面积，返回 RegionResult
- polygon_area(vertices)：鞋带公式
- 全程用 fractions.Fraction 与整数叉积，不碰浮点

现有实现只有这一条枚举路：对每一对直线求交再逐条判定，顶点一多就是平方到立方量级；
交为空、退化成点或线段、或者根本无界时，这套枚举判不出正确形态，只会给出一个错的
顶点集；结果没有区分有界与无界，也没有一条独立的做法可以拿来逐项对照。

## 问题

把现有这套朴素求交扩成能应付大规模与各种退化的实现，缺的东西集中在几处：枚举量太
大，没有按极角排序加双端队列的一趟扫描；判不出空交与退化（点、线段、无界）；没有
一条独立做法在固定输入上逐项对照；异常也还没有统一的基类。
