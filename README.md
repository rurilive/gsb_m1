# memfs

扁平字典式的内存文件存储，纯标准库，无外部依赖。键直接映射到字节串，
写进去、读回来、追加、删掉，就这么点事。

## 现状

memfs/store.py 提供 MemStore：

- write(key, data)：整体覆盖写入，返回写入字节数
- read(key)：取回字节串，键不存在抛 KeyError
- append(key, data)：在已有内容后追加，键不存在则新建，返回总长度
- remove(key)：删除键，返回是否真的删掉了
- size(key)：键对应的字节数，键不存在抛 KeyError
- keys()：全部键，按字典序
- clear() / len() / in：清空、条目数与成员判断

键是普通字符串，彼此独立，没有路径概念，也没有大小限制。

## 问题

键一旦写进去就永远占着，没有目录，没法把一组文件归到一处；键名只是
纯字符串，斜杠没有特殊含义，相对路径、点、点点都解析不了；没有链接，
同一份内容想挂两个名字只能复制，改一处另一处不知情；也没有容量上限，
写多大都照单全收。
