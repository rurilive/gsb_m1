# minrot

纯标准库的循环字符串工具雏形，无外部依赖。

## 现状

minrot/naive.py 提供如下朴素能力：

- min_rotation_index、min_rotation：最小字典序循环旋转的起点下标与旋转串，
  枚举全部起点，逐起点截出等长子串再比较
- max_rotation_index、max_rotation：最大字典序循环旋转，同样枚举全部起点
- is_rotation：两串是否循环同构，枚举一个串的全部旋转与另一个串逐个比对
- min_shift：由一串联左移得到另一串的最短位移，枚举旋转求解
- RotTools：绑定一个串，方法同上并累计字符比较计数，可读取与清零

所有结果都对，但每个起点都要重新比较一遍，没有一趟线性求最小表示的
做法，也没有最大表示、拼接查找与拼接最小表示等互相独立的路。

## 问题

串一长，逐起点比较的次数就随串长的平方往上蹿，同一个起点反复比较的
公共前缀信息完全没被复用；想问多路互相印证也缺独立入口，循环同构与
最短位移只能靠枚举。

## 目标

在当前基础上补出线性最小表示法、最大表示法、拼接查找求最小旋转与
拼接最小表示判循环同构，以及比较次数对照，见任务描述。约束：

- 现有行为与 tests/test_naive.py 基线保持一致（基线一个字不改）
- 纯标准库
- 三路结果逐项一致，并与朴素逐起点枚举一致
