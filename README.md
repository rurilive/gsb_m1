# mpmatch

纯标准库的多模式串查找雏形，无外部依赖。

## 现状

mpmatch/automaton.py 提供一个 Matcher：

- 构造：接受一批模式串，保序去重，空集合法，非序列或空模式报 PatternError
- patterns、len、contains：取回去重后的模式元组及其个数、判断某个模式是否在内
- positions、count：按模式求它在文本里出现的全部起点（升序、允许重叠）与次数
- find_all：一次性返回每个模式的全部起点
- exists：文本里是否存在任意一个模式命中
- compare_count、reset_compare_count：逐字符比对计数的读取与清零

查找只有逐模式、逐位置直接比对这一条路：每求一个模式，就从文本每个起点
起把模式逐字符比一遍。没有字典树，没有失败指针，也没有逐位置结尾的命中
集合。

## 问题

文本一长或者模式一多，比对次数就随位置数与模式长度成倍上涨；每个模式各
扫一遍文本，模式之间共享的相同字符链完全利用不上；想问某个文本位置上
究竟有哪些模式恰好收尾，现在没有这个入口。

## 目标

在当前基础上补出以字典树搭配失败指针的多模式自动机、逐位置结尾的命中集合
与命中汇总，见任务描述。约束：

- 现有行为与 tests/test_automaton.py 基线保持一致（基线一个字不改）
- 纯标准库
- 新老两条路的位置与次数必须逐项一致，自动机只扫一趟文本

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests -v
```
