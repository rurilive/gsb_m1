# bittrie

一个纯标准库的小工具: 维护一个可重复、可增删的非负整数集合, 并回答异或相关的
最值问题。

## 现状

`FlatXorMax` 内部只有一个整数列表。加入就是把元素追加进列表, 删除就是按值从列表
里挪走一个; 与给定值异或最大、异或最小都是从头到尾线性扫描; 集合内两数异或最大
则枚举全部元素对, 平方级。每次查询都要扫全表。

## 问题

查询代价绑死在元素个数上。元素一多, 每次异或极值都是在做无用功, 两数异或最大
更是随元素个数平方增长。集合能加也能删, 但每次删除都要线性找位, 删完之后也没
有任何结构让后续查询变快。

## 目标

把 `FlatXorMax` 从线性扫描扩成以零一字典树为核心的异或最值工具: 整数按固定位宽
从高位到低位插入, 每个节点两个子节点分别表示该位取零与取一, 节点带子树计数以
支持删除; 查询与给定值异或最大时逐位走相反位, 并支持插入、删除、两数异或最大
以及空集与位宽边界等情形。基线那条线性路径保留, 两条路给出的事实要对得上。
详见需求描述。
