# cronix

纯标准库的极简调度小包，无外部依赖。

## 现状

cronix/schedule.py 里是最朴素的一版调度器 Scheduler：

- 表达式只有一个分钟字段，且只能是单个整数（0 到 59）
- match 判断给定时刻是否命中：时刻的分钟等于表达式数字即命中
- describe 返回人类可读描述
- 没有范围、步长、列表，没有多字段，没有下次触发计算
- cronix/__init__.py 只导出 Scheduler

时间一律由外部传入（注入时钟），本身不读取真实时间。

## 目标（见任务描述）

把 cronix 从整分调度扩成完整的 cron 表达式解析与求值：解析五字段（分、时、
日、月、星期）表达式，支持星号、单值、范围、步长、列表及其组合，解析成字段
集合；日字段与星期字段按或逻辑组合（哪一字段受限就按哪个）；给定注入时刻判断
是否命中，边界（月末、闰年、跨月）要正确；从给定时刻算出下次触发时点，跨日跨月
跨年正确，并与逐分钟推进的暴力口径一致；能展开给定区间内全部触发时点，数量与
下次触发迭代结果一致；非法字段值（越界、非法步长、字段个数不对、未支持的宏名）
一律 fail fast 抛异常，异常继承 CronError 基类。全部仍在 cronix 包里，纯标准库，
用注入时钟做确定性。约束：

- 现有行为与 tests/test_schedule.py 基线保持一致（基线一个字不改且必须全绿）
- 新行为另开 tests/test_cron.py，用固定表达式与固定时刻断言
- 纯标准库，不引第三方
