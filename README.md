# lct

用邻接表加深搜维护一片带点权森林的小工具，纯标准库，无外部依赖。

## 现状

lct/forest.py 只有一个朴素实现，Forest 直接在邻接表上加边、删边、做查询：

- connected(u, v)：从 u 起深搜整棵连通树，看能否走到 v
- link(u, v)：两个方向各记一条邻接边，连前先查一次连通性
- cut(u, v)：在两边邻接表里各扫一遍找对端再删
- path(u, v)：从 u 起深搜，摸到 v 后沿父指针回溯出整条路径
- path_sum / path_min / path_max(u, v)：拿到路径顶点后逐个累加或比较
- set_value(u, x) / get_value(u)：点权读写

没有树、没有分层结构，每次查询都重新遍历整片森林，规模一大就退化成
线性甚至更高。

## 问题

重复的连通性与路径查询每次都从头重搜，压不下代价；没有一条按需伸展、
把均摊代价压下来的路径；也没有独立的朴素路径与升级后的路径逐项对照。
