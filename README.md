# rex

自研正则表达式引擎，纯标准库，Python 3.10+，无外部依赖。

## 现状

`rex/engine.py` 只提供字面量相等判断，模式里不认识任何语法元字符：

- `match(pattern, text)`：从开头匹配，要求整段文本等于模式，命中返回 `(start, end)`，否则 `None`
- `search(pattern, text)`：任意起点搜索，当前退化为起点 0 的相等判断
- `findall(pattern, text)`：返回全部命中文本，当前至多给一个结果

模式里的 `.`、`*`、`[`、`(` 等目前都只当作普通字符看待。

## 问题

现有实现显然撑不起一个正则引擎：没有语法解析，没有量词，没有字符类与锚点，
没有或分支与分组，更没有捕获。匹配只会拿整串做相等比较，一旦文本里只想命中
某一段就只能干瞪眼，`search` 与 `findall` 也因此形同虚设。
