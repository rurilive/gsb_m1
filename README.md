# satx

一个只用 Python 标准库的二元可满足性小工具，纯内存，无外部依赖。

## 现状

`satx/twosat.py` 提供 `TwoSat`，管一组布尔变量（从一编号）与若干二元的或约束，
约束之间按合取叠加。文字用带符号整数表示：正 k 表示变量 k 取真，负 k 表示取反。
当前所有结果都由枚举驱动：

- `TwoSat(var_count)`：建一组变量，变量个数为负或非整数立刻报错
- `add_clause(left, right)`：加一个两个文字的或作为约束，返回自身
- `clauses()` / `clause_count()` / `var_count()`：读约束与变量个数，保持加入顺序
- `enumeration_size()`：朴素路径要逐个检查的完整赋值个数，即二的变量个数次方
- `is_satisfiable()`：逐一枚举全部赋值，看有没有一组满足全部约束
- `solve()`：按固定枚举顺序给出第一组满足全部约束的赋值，没有则返回 None
- `value_of(var)`：某变量在所选方案中的取值，判不出方案时返回 None
- `satisfied_count(assignment)`：给定完整赋值下被满足的约束条数
- `count_models()`：枚举全部赋值，数出满足全部约束的赋值个数

## 问题

枚举的量随变量个数指数增长：判定、给方案、取某变量取值、数满足条数，全部
要把二的变量个数次方组赋值挨个走一遍，变量一多就迅速撑不住；约束之间蕴含
出来的结构没有被利用，也没有任何计数能说明一条更聪明的做法省了多少。

## 目标

在当前基础上，以蕴含图强连通分量为核心把 `TwoSat` 扩成 2-SAT 工具集，
见任务描述。约束：

- 现有行为与 `tests/test_twosat.py` 基线保持一致（基线一个字不改）
- 纯标准库，不得引入任何外部依赖
- 枚举那套朴素路径保留，新老两条路对同一批数据给出的事实必须一致
