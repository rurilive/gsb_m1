# idxstore

文档检索服务的倒排索引，纯标准库。

- `idxstore/store.py`：内存正排 + 倒排，攒够 `snapshot_every` 次变更就整份全量落盘
- `tests/test_store.py`：行为基线
- `demo.py`：写入、检索、落盘、重载演示

## 实现说明

1. WAL 为 `index.wal.log`，每行一条 `长度:crc32:json` 记录，payload 是 `["put"|"delete", doc_id, text]`，delete 的 text 为 null。
2. 每次变更先追加 WAL、`flush`+`fsync` 落盘，再改内存；全部变更走同一把锁，日志顺序即内存生效顺序。
3. 恢复时先读整份快照重建正排/倒排，再从快照后留下的 WAL 顺序重放；无快照则只重放 WAL。
4. `put` 重放为整体覆盖、`delete` 重放对不存在的文档为空操作，日志即使与快照状态重叠也幂等，删掉的文档不会复活。
5. 快照仍是临时文件 + `os.replace` 原子落盘，落盘并 fsync 目录后才删除 WAL；崩溃时两者必有一个完整，不存在“快照有、日志半裁”的错位。
6. 裁剪时机：自动/手动快照成功即删 WAL（快照已含全部状态），既控磁盘占用，也让恢复最多重放一个快照周期的变更。
7. 坏记录（掉电写了一半、长度不符、crc 不过、格式非法）在重放处即停，截断丢弃坏尾巴后继续追加，不再抛异常；写快照残留的临时文件启动时清理。
