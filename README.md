# maxrect 零一网格子矩形工具（改造前基线）

## 现状

包 `maxrect` 以零一矩阵（或带权矩阵）为底座，提供四条能力：

- 全一子矩形的最大面积与一个具体位置（`brute_max_rect`）；
- 全一子正方形的最大面积与最大边长（`brute_max_square`）；
- 带权矩阵下权值和最大的子矩形与权值和（`brute_max_weight`）；
- 每一格向上连续一的悬线高度整表（`simple_heights`）。

另有一条直接用悬线法思想实现的独立慢速做法 `independent_suspend`，用于与主路径对账。

## 问题

当前实现全部是朴素枚举：对每一对上下边界与每一对左右边界构成四元组，逐个候选矩形
再逐格检查是否为全一（带权则逐格累计权值），是四次方以上量级。结果正确，但规模一大
就飞快变慢，无法在较大矩阵上直接使用。

## 目标

在保持现有四类结果口径不变的前提下，改造成线性或平方量级的悬线法实现，并保留一条
独立印证路径（按行单调栈求柱状图最大矩形）与朴素路径在小矩阵上逐项一致；同时暴露
朴素枚举次数与悬线法访问次数的规模对照，覆盖空矩阵、全零、全一、单行、单列、含零行
分隔、最大矩形贴边界、权值含负等边界。
