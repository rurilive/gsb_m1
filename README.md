# balancedbst

一个只用 Python 标准库的自平衡有序二叉树工具包。包内模块 tree.py 提供
BalancedBST 类，往树里插入、删除、查找整数键，允许重复键，给出中序序列、
树高、最小与最大键，并用一个结点访问计数暴露每次操作的真实代价。

## 现状

内部只是一棵最普通的二叉搜索树：每个结点只有左右孩子指针，不带任何高
度、颜色或平衡因子。插入按值大小递归下降，落到底就挂一个新叶子；删除
找到目标后，若它有两个孩子就用中序后继顶替；查找同样从根按值大小下降。
规模小时结果一眼能看穿，也从来没有出过错。

## 问题

整棵树没有任何旋转或高度维护，树高完全取决于键的到达顺序。一旦把键按
升序或降序灌进去，树就会一路往单边挂成一条链，单次操作最坏要走过与元
素个数成正比的结点，深度逼近元素个数。既没有按子树高度做单旋双旋把树
压回对数级的路子，也没有颜色规则让最长路径不超过最短路径的两倍，更没
有一个专门量树高与访问结点数的出口把差距摆出来。

## 目标

把 BalancedBST 从普通二叉搜索树扩成带旋转维护高度平衡的自平衡树：插入
与删除按子树高度或颜色规则做单旋双旋，把树高始终维持在对数量级；查找
仍旧从根按值大小下降。新路径与基线朴素路径对同一批键的中序序列、规模、
查找结果与删除结果必须逐项一致。要能暴露朴素树高与平衡树高之间的差距，
覆盖空树、单结点、重复键、有序插入、倒序插入、删除叶、删除双分支结点、
删除不存在键等边界；异常统一继承 BalancedBSTError 基类并快速失败；基线
那条朴素路径一条都不许删，固定输入重复跑结果一致，不依赖模块级可变状态。

    python3 demo.py
    python3 -m unittest discover -s tests
