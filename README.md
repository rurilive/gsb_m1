# segtree

一个纯标准库的区间统计小仓库，当前只有改造前的基线实现。

## 现状

包名 segtree，核心模块是 range，核心类是改造前的朴素区间数组。内部用一个
列表把数据存起来，区间操作一律逐项扫过区间：

- 区间加对半开区间逐项累加；
- 区间求和逐项累加一遍，空区间返回零；
- 区间求最大值逐项比较，空区间返回约定的空值；
- 单点读取与设值直接落到列表下标上；
- 长度就是列表长度；
- 区间非法（左端点大于右端点、越界、负数下标）一律报错，fail fast，不悄悄修正。

## 问题

两头都慢。每做一次区间操作都要把区间整个重扫一遍，改一个元素之后原先算过的
区间结果也留不下来，操作一多就白扫；而且逐项路径之外没有任何可复用的结构。

## 目标

把它从逐项操作扩成以线段树加懒标记为核心的区间统计工具，纯标准库。区间加与
区间求和、区间赋值与区间求和、区间加与区间最值、区间乘与区间加混合都要与逐项
暴力口径逐项一致；单点查询要把祖先标记一路下推到底；懒标记只在必要时下推并
暴露可读的下推次数；区间操作的访问节点数要明显小于逐项扫描次数；空区间、单
元素、整段区间、越界下标都要正确。基线那套逐项路径不许删，两条路对同一批数据
给出的事实必须对得上。异常统一继承基类。
