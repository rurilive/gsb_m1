# shardstore

缓存层的内存键值表，纯标准库，分片集合在建表时定死。

- `shardstore/store.py`：`ShardedKV` 的 `put()` / `get()` / `delete()` 读写，`shard_of()` 查键落在哪片，`keys_in()` / `size()` / `distribution()` / `total()` 看分布
- `tests/test_store.py`：行为基线
- `demo.py`：读写与分布演示

## 实现说明（在线分裂）
1. 路由：不重取模，老片记录 (m,b) 按 h%2m 对半，(b) 留老片、(b+m) 去新片；分裂中已提交路由仍指老片。
2. 双读双写：读先问影子新片、没有回老片捞；判定搬走的键写两边，留下的只写老片，搬走后热点重写也不漏。
3. 迁移：`migrate()` 分批在新老两锁内交接，搬过的键脏了提交前再扫一遍，别的片全程不动。
4. 进度：`progress()` 实时给 moved/remaining/total/fraction，迁移期间线上读写不中断。
5. 存进度：state_dir 下写操作先 fsync 进 WAL，交接游标按批原子重写检查点。
6. 断点续：重启 `open()` 读快照+回放 WAL、挂回分裂，done 游标内的键不重搬，从断点接着走。
7. 原子切换：提交在两锁内清空残键，新快照+manifest 一次 rename 钉死路由，然后才转正新片，没有半新半旧。
8. 回退：`abort()` 把新片合回老片、回滚 WAL 并换快照，路由整体退回分裂前，要么全成要么全退。
9. 连续劈：新片继承同一套 (m,b) 规则可继续二分，路由按大模数优先匹配，片数涨了不退化、别片零搬迁。
