# sccdag

一个只用 Python 标准库的有向图可达小工具。包内模块 graph.py 提供
ReachGraph 类，用邻接表保存一张有向图，节点只要求可哈希，本模块不解释
节点含义。

## 现状

ReachGraph 支持加节点、加边、查询邻居、查询出度，以及单点可达与两两互达
判断。可达的做法很朴素：每次都从起点重新做一次深度优先搜索，只回答这一对
点，不缓存任何中间结果。凡是涉及互达或同分量的判断，都要正反各跑一遍遍历，
分量相关的信息只能靠成对询问拼出来。

## 问题

每问一对点就要跑两遍遍历，问遍所有点对时整体代价迅速膨胀；更根本的是，
当前代码里既没有分量这个实体，也拿不出任何一个分量编号，调用方无法知道
整张图被切成几块、每块有多大、块与块之间是什么偏序，只能反复用两两判断去
近似，既慢又散。

## 目标

把 ReachGraph 从两两可达判断扩成以强连通分量与缩点为核心的图算法工具：
一次深度优先加栈分解出全部强连通分量，给出每点分量编号、分量大小与个数，
把每个分量缩成一个点得到无环的缩点图，并让分量内可达与分量间偏序可达都能
按缩点图逐点核对；分解代价要与边数和点数线性，明显低于两两遍历的总量；
空图、单点、自环、平行边、不连通、大环、链式无环等边界都要有确定行为；
固定图重复分解结果完全一致；异常统一继承基类，非法节点快速失败。
