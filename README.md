# ropetex

一个纯标准库的 Python 文本缓冲库。

## 现状

当前只有最朴素的实现。文本整体存在一个 Python 字符串里（`FlatText`），
插入按位置切片再拼接，删除用切片跳过区间，`charAt` 直接取下标。
没有树结构，没有分块，没有结构共享，也没有任何平衡机制，因此在大文本上
反复插入删除会出现整串拷贝与线性开销。

基线行为由 `tests/test_text.py` 锁定，包含初始化、取字符、取子串、
插入、删除、越界与类型错误的语义。

## 目标（见任务描述）

把 `ropetex` 从扁平字符串扩成绳式文本结构，公开能力与可断言口径以任务
描述为准。目标实现不在本基线内，`demo.py` 第二段与本文末尾的说明均为占位。

## 运行

```
python3 demo.py
python3 -m unittest discover -s tests -v
```
