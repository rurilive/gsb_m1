# mobius

一个只用 Python 标准库的莫比乌斯反演与数对计数小工具。包内模块 mobius.py 提供
Inversion 类，围绕一个上界做反演与统计：mobius 求单个数的莫比乌斯函数值，
mobius_values 求一到上界每个数的莫比乌斯函数值，gcd 求两个数的最大公约数，
count_coprime_pairs 统计不超过上界的互异数对里互素的个数，count_pairs_gcd
统计一到上界间有序数对里最大公约数恰为某个值的个数，count_coprime_pairs_in
统计一批整数里互素的下标对个数。

## 现状

莫比乌斯函数一律对每个数单独做质因数分解、再逐个判断有没有重复的质因子；
数对计数一律用双重循环逐对枚举、逐对求最大公约数再判定。数小、上界低的时
候直观可靠，结果也一目了然。

## 问题

逐对枚举的计算量随上界平方级增长，上界一大就慢得刺眼；莫比乌斯函数也逐数
重复分解同样的因子。当前实现既没有一趟线性筛顺带筛出质数、莫比乌斯函数与
最小质因子的路径，也没有按倍数贡献做前缀累加把反演求值降到近似线性对数级
的手段，无法说明一条更聪明的做法到底省了多少。

## 目标

把 Inversion 从逐数枚举扩成以线性筛为核心的反演工具：一趟线性时间同时筛出
质数、莫比乌斯函数与最小质因子；再按倍数贡献用类似埃氏筛的调和级数方式对
多个倍数做前缀累加，把互素数对与最大公约数恰为某值的数对计数从平方降到近
似线性对数级；另起一条独立做法（逐对枚举求最大公约数）在固定输入上与快速
路径逐项一致；覆盖上界为零或一、互素数对计数、最大公约数为一、全同、一列
到某个上界、单元素等边界；暴露逐对枚举次数与线性筛标记次数的差距；异常统
一继承 Erro 基类并快速失败；基线那套逐数枚举路径不许删。
