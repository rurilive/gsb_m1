# bloomx

埋点去重用的布隆过滤器，纯标准库，容量在建实例时定死。

- `bloomx/filter.py`：`BloomFilter.add()` / `in bf` / `len(bf)` / `to_bytes()` / `from_bytes()`，按容量与目标假阳性率算位数组大小
- `bloomx/shard.py`：`ShardedBloomFilter`，写满自动在线添片，旧片冻结、全片查询
- `tests/test_filter.py`：单实例行为基线（格式锁死）；`tests/test_shard.py`：分片新行为
- `demo.py`：第一段定容单实例，第二段在线扩容演示

## 实现说明

1. 片就是固定容量的 `BloomFilter`；写满自动 `add_shard()` 挂一片，旧片冻结只查不写，添片在锁内完成，不停机、并发写不丢。
2. 写入永远只进当前末片；查询问遍所有片，任一片命中即命中——漏查一片就会假阴性，去重失效。
3. 新片目标假阳性率按 `p(1-r)、p(1-r)r、p(1-r)r²…` 几何收紧（r 默认 0.5），保证各片目标之和不超过整体目标 `p`。
4. 整体假阳性率只报一个数：`1-Π(1-pᵢ)`，`pᵢ=(1-e^(-kᵢnᵢ/mᵢ))^kᵢ` 按每片真实写入量 `nᵢ` 计算，不按片各报各的。
5. 磁盘用 `BLMS` 格式逐片保存、原子 rename 落盘；读到老 `BLM1` 单实例文件自动当首片载入，原片字节不动、照常添新片。
6. 内存兜底：`max_shards` 封顶；显式添片抛 `ShardFullError`，自动增长封片后新写落入末片（以假阳性换不丢数据），重启后状态保留。
