# pathcover

一个只用 Python 标准库的有向无环图最小路径覆盖小工具，纯内存，无外部
依赖。

## 现状

`pathcover/covering.py` 提供 `PathCoverer`，维护一张有向图：点是任意可
哈希对象，边有向，用有序对集合表示，重复边只算一次，自环与空点当场拒
掉。当前结果一律靠枚举顶点划分得到：

- `add_edge(u, v)`：加一条有向边，重复边不重复计，返回自身
- `add_node(v)`：登记一个孤立点，返回自身
- `nodes` / `edges()` / `node_count()` / `edge_count()` / `successors(u)` /
  `predecessors(u)`：读图，边按两端稳定排序后给出
- `has_edge(u, v)`：从 u 到 v 是否有边
- `min_path_count()`：枚举全部顶点划分成路径的方案，取条数最少的
- `min_path_cover()`：给出一个最小路径覆盖方案
- `is_valid_cover(cover)`：把给定覆盖按同样的检查走一遍

## 问题

枚举的量随点数指数增长：求最小路径覆盖要把顶点如何划分、每条路径里点
如何排列的组合挨个走一遍，判断一个覆盖是否合法又要再走一遍。点数稍多
就迅速撑不住，而且当前既没有拆点建二分图求最大匹配的观念，也没有任何
计数能说明一条更聪明的做法省了多少。

## 目标

在当前基础上，以拆点建二分图求最大匹配为核心把 `PathCoverer` 扩成有向
无环图最小路径覆盖工具集，见任务描述。约束：

- 现有行为与 `tests/test_baseline.py` 基线保持一致（基线一个字不改）
- 纯标准库，不得引入任何外部依赖
- 枚举那套朴素路径保留，新老两条路对同一批数据给出的事实必须一致

```bash
python3 demo.py
python3 -m unittest discover -s tests
```
