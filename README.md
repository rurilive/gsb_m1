# treemo

树上路径查询工具包，纯标准库，无外部依赖。给一棵带点权的树，离线回答若干条
路径查询，并支持路径上的派生统计。

## 现状

朴素实现，能算对但规模一大就慢。

- `treemo/naive.py`：`build_tree()` 把父指针与点权规整成字典，`node_path()`
  沿父指针回升拼出两点路径；`PathQuerier` 每次查询都先把路径上的全部顶点
  逐点走一遍再统计，`path_distinct()` 求路径上不同权值个数，`path_sum()`
  求路径权值和，`path_max()` 求路径最大值，`path_count()` 求某权值出现次数，
  `path_mode()` 求出现次数最多的权值（并列取权值最小），`run()` 对一批查询
  逐条回答并给出每条结果与一个总核对值，`walk_steps()` 与 `step_count()`
  暴露逐步次数；异常基类 `QueryError` 与两个子类也在本文件。

单次路径查询与路径长度成正比，同一段路径被反复重扫；查询一多，总代价就是
查询条数乘路径长度的量级。

## 问题

没有把树压成一维序列来批量维护区间，每次查询都从零重走一遍；路径上可加的
统计与不可加的统计混在同一条逐点路上，没有可对照的规模指标，慢在哪看不出来。
