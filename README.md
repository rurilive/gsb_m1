# booklib

一个纯标准库、无外部依赖的 Python 订单簿包。眼下只提供最朴素的订单簿
FlatBook：买盘卖盘各一条订单列表，一切查询都靠线性扫描。

## 现状

booklib/orderbook.py 提供 FlatBook：

- add(side, price, qty)：在某侧追加一条订单，返回递增的订单号
- best_bid()：买盘最高价，空盘返回 None
- best_ask()：卖盘最低价，空盘返回 None
- qty_at(side, price)：该价位上所有订单的数量之和
- cancel(order_id)：按订单号删除，成功返回 True，不存在返回 False
- orders(side)：该侧订单快照，按加入先后给出
- len()：两侧订单总数
- BUY / SELL：买卖方向常量；BookError：异常基类

它既不按价位聚合档位，也没有任何撮合能力。

## 问题

每次问最优价都要从头扫一遍全表，订单越多扫得越久，插入与查询的量级
完全绑在一起；同一个价位上的多笔订单也从不合并，既看不出档位深度，
更没法按价格优先、时间优先去撮合。它只能挂单和撤单，吃单这件事它做不到。
