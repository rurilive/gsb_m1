# txbox

纯标准库的事务小引擎，无外部依赖。

## 现状

txbox/engine.py 只提供最朴素的全局锁事务：

- LockedTxn(initial=None)：一块按 key 索引的共享存储，可选初始数据
- begin()：抢下一把全局锁并开启事务，同一时刻只允许一个事务在跑
- get/set/delete：在事务内读写共享存储
- commit()：提交并放锁；rollback()：把存储恢复成 begin 时的整块副本并放锁
- committed：读当前已提交数据
- 事务外的读写、重复 begin、已结束事务再操作都抛 TxnError 的子类
- 没有快照、没有版本链、没有并发读写，也没有任何冲突检测

tests/test_engine.py 把上述基线行为锁住，一字不改。

## 目标（见任务描述）

在现有 LockedTxn 之上把 txbox 扩成快照隔离的事务引擎：事务开始时取一次
快照，整个事务期间读到的是同一快照，别的事务的提交对它不可见，实现可重复读；
每次写产生新版本并保留旧版本，读取按快照版本选合适的版本，旧版本按规则回收；
两个并发事务写同一键时后提交者检出写写冲突并被中止，first-committer-wins，
被中止事务的改动全部不生效；范围读要能检出插入造成的写偏斜或按明确口径处理，
冲突判定与键的读写集合相关；提交是原子的，回滚后引擎状态与事务开始前一致，
重复回滚或提交已结束事务 fail fast；可选地提供串行化校验，检出危险的读写依赖
环并中止其一，不实现则明确记录为不支持的隔离级并断言。调度要可注入，用固定
时序保证确定性。全部仍在 txbox 包内，纯标准库。
