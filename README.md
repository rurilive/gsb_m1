# linbasis

异或空间与线性基工具，纯标准库，无外部依赖。

## 现状

`linbasis/core.py` 提供一组朴素但正确的枚举实现：

- `XorSpace(numbers)`：一组整数构成的异或空间，元素须为非负整数且不超 64 位位宽
- `XorSpace.numbers`：按登记顺序给出的元素元组
- `max_xor()`：枚举全部子集，在子集异或和里取最大值
- `min_xor()`：枚举全部子集，在子集异或和里取最小值，空集算零
- `xor_space_size()`：枚举全部子集异或和，集合去重后数个数
- `kth_xor(k)`：枚举全部异或和，排序去重后按下标取第k小
- `can_represent(target)`：枚举全部子集逐个比对，判断能否异或得到 target
- `merge_spaces(other)`：把两组元素拼接后交给新的工具重新枚举
- 计数器 `subset_count` 与 `xor_steps`：记录一次查询枚举的子集个数与异或运算次数

所有对外异常都继承 `LinbasisErro`，固定输入重复调用结果一致，不依赖模块级可变状态。

## 问题

只有一层朴素枚举：任何查询都要把二的n次方个子集走一遍，每个子集再逐个元素
异或，元素一多就是指数级，规模一大就跑不完；判定能否异或表示同样枚举全部
子集，不同异或值个数与第k小又把全部结果堆起来排序去重，没有一趟就能建成的
按位结构，也没有规模计数能把枚举量与插入次数摆在一起对照。

## 目标

在上面的基础上补出按位维护的高斯消元基，一趟插入、按位查询，四条能力分别是
最大异或和、最小异或和、第k小异或和、能否异或表示，再接线性基合并与异或空间
大小两个独立印证，并让新老两条路径对同一批数据逐项一致。见任务描述。约束：

- 现有行为与 `tests/test_core.py` 基线保持一致（基线一个字不改）
- 新行为另开测试文件
- 纯标准库，Python 3.10+

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests -v
```
