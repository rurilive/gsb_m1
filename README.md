# prefixsum

纯标准库的区间和工具雏形，无外部依赖。

## 现状

prefixsum/sum.py 提供一个 ScanSum：

- 初始化：用一串整数建起来，bool 不算整数，非整数报 ValueError
- 下标访问与 to_list：按下标取回单个元素，to_list 返回底层数据的一份副本
- query：唯一的区间入口，半开区间 [left, right)，空区间返回 0，
  这一步从区间起点开始把区间里的元素挨个累加，看过几个元素就是几个元素的代价
- update：把某个下标处的元素直接加上一个增量，返回加完之后的新值，越界报 IndexError
- last_cost：上一次 query 看过的元素个数，用来观察逐项累加的代价

查询只有逐项累加这一条路，区间一长就要把区间里每个元素都摸一遍；点更新
也只是就地改一个格子，改完之后其它区间的查询还是要从头再算；没有树状数组，
没有按二进制的下标跳转，没有差分，没有二维结构，也没有逆序对与前缀最值。

## 目标（见任务描述）

在当前朴素逐项累加的基础上扩成树状数组，全部仍放在 prefixsum 包里，纯标准库。
约束：

- 现有行为与 tests/test_sum.py 基线保持一致（基线一个字不改）
- 新行为另开 tests/test_fenwick.py，用固定种子与逐字断言
- 树状数组只该换掉算的路径，不该改结果：点更新、前缀和、区间和、区间更新后
  的结果都要与逐项累加或暴力口径逐项一致
