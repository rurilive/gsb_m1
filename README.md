# matx

一个只用 Python 标准库的整数矩阵小工具。包内模块 mat.py 提供 NaiveMat 类，
把方阵用二维列表存起来：mul 逐项相乘、power 求幂、add 逐项相加；另有一组模块级
函数 mat_zeros、mat_identity、mat_diagonal 负责零矩阵、单位矩阵、对角矩阵的构造，
mat_mul、mat_add、mat_power 提供函数式入口，fib 求斐波那契数。

## 现状

NaiveMat 的求幂一律靠连续自乘：把单位矩阵与底矩阵反复相乘 n 次，指数多大就乘
多少次；乘法本身是三重的逐项乘加，求一个 n 阶方阵的乘积要跑 n 的三次方次乘加。
斐波那契靠从零开始逐个递推，下标多大就走多少步。做法直观可靠，规模一小看不出
问题。

## 问题

连续自乘的乘法次数与指数同量级，指数一大就白乘一多半；逐项乘加的立方级开销叠
上去更吃力。当前实现既没有二进制拆分快速幂的观念，也没有任何把乘加次数与操作
步数量出来的手段，无法说明一条更聪明的做法到底省了多少，更谈不上把斐波那契和
一般的线性递推纳入同一套加速框架，也无法在取模口径下给出大下标的答案。

## 目标

把 NaiveMat 从朴素循环扩成以快速幂加递推加速为核心的矩阵工具：乘法仍与朴素口径
一致并报告乘加次数；用二进制拆分的快速幂求矩阵的 n 次幂，与连续自乘逐项一致；
用矩阵快速幂求斐波那契，与逐个递推一致并可带模；给定线性递推关系求第 n 项，n
取很大值时仍能给出答案；单位矩阵、零矩阵、对角矩阵的幂与暴力一致；用计数断言
快速幂的乘法次数随指数位宽线性、明显小于连续自乘的指数次；带模与不带模下的乘积
取模后一致；覆盖指数为零为一、一乘一矩阵等边界；异常统一继承基类并快速失败。
