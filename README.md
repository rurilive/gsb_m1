# diff3x

配置/文本三方合并（diff3），纯标准库。输入输出都是完整文本，典型用途是把
各环境对同一份基线配置的改动合回主线。

## 语义约定（以下为本模块的正式行为定义）

1. **输入与切分**：`merge(base, a, b)` 三个参数均为完整文本（str），按 `'\n'` 切分为行，行内不含 `'\n'`；以换行结尾的文本切分后末位是空串，拼接时还原。
2. **换行处理**：行比较前剥离行尾 `'\r'`，CRLF 行与 LF 行视为同一行，**仅 `'\r'` 差异不构成改动**；输出保留来源行的原始内容（含 `'\r'`）。
3. **改动区域**：以 base 的行坐标为基准，每侧相对 base 的改动表现为若干替换区域（含插入与删除）。
4. **合并规则**：仅一方改动的区域取该方内容；双方均未改动的区域取 base。
5. **冲突判定**：双方改动区域在 base 坐标上相交时——
   - **双方替换内容完全相同 → 干净合并，只保留一份**；
   - **一方删除（替换为空）、另一方修改 → 冲突，任何一侧都不得被静默丢弃**；
   - 其余情况 → 冲突。
6. **冲突块边界**：**冲突块只覆盖双方改动基区的并集，紧邻的未改动行不得并入冲突块**。
7. **结果结构**：返回 `MergeResult`——
   - `lines`：list[str]，干净区域按序拼接；冲突处插入标记块，依次为 `<<<<<<< a`、a 侧行、`||||||| base`、base 侧行、`=======`、b 侧行、`>>>>>>> b`，七个标记行顶格；
   - `conflicts`：list[Conflict]，每个含 `base_lines` / `a_lines` / `b_lines` 与 `base_span` / `a_span` / `b_span`；**span 为 0 起始、含头不含尾的 (start, end) 行区间**，对应该侧在冲突块中的行范围；
   - `clean`：conflicts 为空即 True。

## 运行

```bash
python3 demo.py
```
