# circlp

环形序列最优化工具，纯标准库，无外部依赖。

## 现状

circlp/circular.py 提供 CircularOpt：

- CircularOpt(values)：以环形序列为底座，首尾相邻，元素须为数值，空环合法，
  单元素与两元素按退化情形处理
- brute_max_sum()：不相邻选取最大和，选了首就不能选尾，枚举断点拆环再对每条
  链指数枚举互不相邻子集，全负时允许空取记零
- brute_max_segment()：环形最大子段和，枚举断点拆环后平方枚举全部连续子段，
  子段可跨界，全负时允许取空子段
- brute_best_partition(parts)：把环划成指定段数，求各段和最大值的最小可能值，
  枚举断点拆环后枚举全部断点组合
- brute_plan()：不相邻选取的最优方案，返回下标集合，并列时按下标序列字典序最小
- brute_diff_sum()：环形上相邻差最大和，分子集指数枚举
- brute_min_delete(count)：删除给定个数互不相邻元素的最小代价
- independent_split()：独立做法一，必不选首与必不选尾两侧分别线性递推
- independent_minus()：独立做法二，用总和减去中间最小子段
- break_trial_count / linear_step_count / minus_step_count：上一次计算的枚举次数

长度一多这些做法就露怯，断点试探次数随长度呈平方乘指数增长，但结果正确。

## 问题

枚举断点拆环把同一个环按每个起点各拆一遍，断点一个不漏地试，再对每条链做
指数级子集枚举或平方级子段枚举，量级是平方乘指数；既没有把必不选首与必不选尾
两种情况分开、各做一遍线性递推再取较大者的手段，也没有用总和减去中间最小子段
求环形最大子段和的独立口径，更拿不出任何计数说明省了多少。两条独立慢速做法与
升级路径之间没有逐项核验，空环、单元素、两元素、全正、全负、含零、首尾相邻的
退化情形、环退化成链、最大和为整个环这些边界只能靠肉眼去猜。
