# joseph

纯标准库的约瑟夫环淘汰过程工具雏形，无外部依赖。

## 现状

joseph/core.py 提供一个朴素模拟器与一批批量求值入口：

- Josephus：绑定人数、步长、起点与起始编号口径，用列表反复切片与旋转模拟
  圆圈，每淘汰一人就从当前位置重新数 k 个、把剩下的人整体搬家一次
- order、survivor、rank_to_be_removed、elimination_index：求完整淘汰序列、
  最后幸存者、第 m 个被淘汰者、某编号的淘汰次序
- move_count、move_counts_per_step：暴露朴素路径每次淘汰的搬家步数与累计
- BatchFacts：对一批人数与步长一次性求出上述各项事实

所有结果都对，但每淘汰一人都要把剩下的人整体搬家一次，淘汰线性、整轮平方
量级；求幸存者也要整轮模拟到底，没有按人数递推的常数步做法。

## 问题

人数一多，搬家步数按人数平方上涨，规模一大就慢；同一个淘汰过程的序列、
幸存者、第 m 个被淘汰者全靠同一套模拟重复跑，没有互相印证的第二、第三条
独立路径；从头开始编号、步长为一、步长大于人数等口径也只有模拟一条路。

## 目标

在当前基础上补出三路独立做法与变体口径对照，见任务描述。约束：

- 现有行为与 tests/test_naive.py 基线保持一致（基线一个字不改）
- 纯标准库
- 数学递推路、平衡结构路、分块跳跃路与朴素模拟在同一批参数上逐项一致，
  变体口径各自单独断言
