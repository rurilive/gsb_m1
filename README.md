# lcsalign

最长公共子序列与序列比对，纯标准库，无外部依赖。

## 现状

`lcsalign/sequence.py` 提供：

- `lcs_length(a, b)`：用枚举第一个序列全部子序列的朴素做法求最长公共子序列长度
- `lcs_sequence(a, b)`：在同一枚举下取具体子序列，并列时取最靠前搭配的字典序最小者
- `summary(a, b)`：返回长度与子序列的字典，供交叉核对使用

序列按位置逐元素比较，元素要求可比较相等；空序列抛 `EmptySequenceError`。

## 问题

枚举全部子序列的条数随序列长度指数级上涨，长度稍大就慢到无法使用；没有动态规划概念，也没有多序列或多重公共子序列口径，缺少最长公共子串这类连续口径与最长递增子序列能力。
