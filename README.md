# sqrtds

一个只用 Python 标准库的小仓库，提供可变序列上的序列操作工具集。

## 现状

- 包名 `sqrtds`，核心类 `Sequence`，位于 `sqrtds/seq.py`。
- 内部只有一份平铺的 list，元素按构造给出的顺序保存，允许负数。
- `sum_range(left, right)` 对半开区间 `[left, right)` 内每个位置逐个累加，空区间返回 0。
- `add_range(left, right, delta)` 用循环对区间内每个位置逐个累加。
- `max_range` 逐个比较出区间最大值，空区间抛 `EmptyRangeError`。
- `count_range(left, right, value)` 数出区间内等于 value 的个数。
- `get(index)` / `set(index, value)` 直接读改数组里的单点，越界抛 `IndexOutOfRangeError`。
- `element_touches` 暴露累计的元素访问次数，`replay(values, operations)` 在副本上回放一串操作。
- 所有自定义异常继承自 `SqrtdsError`。

## 问题

每次区间求和、区间加、区间最大值或区间计数都要对区间内每个位置逐个重扫
一遍，单点读改虽然是常数量级，但改完之后没有任何聚合量可以复用。规模一
上来，每次操作的代价就随区间长度成正比上涨，序列里也没有任何分块或层级
结构。

## 目标

把核心加厚成以分块（根号分治）为一条路的序列工具集：把序列切成若干个大小
约为根号长度的块，每块维护加标记与块内和或块内最大值；整块命中的操作只改
标记，残缺块才逐元素处理，使区间修改与区间查询落在根号量级。另一条路用
线段树或树状数组独立维护区间加与区间和（懒标记），与分块路逐项一致且互不
调用，两路再与朴素逐元素路在中小规模上逐项一致。覆盖区间加后区间求和、
区间最大值、单点查询与区间求某值出现次数四条能力，给出每次操作后某查询的
确定结果，并支持批量混合操作后的一致性断言；对外暴露朴素逐元素处理次数与
分块整块标记加零散处理的规模对照。
