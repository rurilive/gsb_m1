# calipers

一个只用 Python 标准库的平面点集几何度量工具包。包内模块 calipers.py 提供
CalipersKit 类，围绕平面点集做八件事：convex_hull 求凸包，closest_pair 求最近
点对，hull_diameter 求凸包直径，min_width 求最小宽度，max_triangle 求最大三角形，
circumcircle 求最小包围圆，contains 判断某点是否落在凸包内，
min_area_rect 求面积最小的轴对齐外接矩形。

## 现状

八件事一律靠朴素做法：凸包枚举每一对点，看其余点是否都落在它的一侧，据此判定
这条有向直线是不是边界，再把边界串成环、把落在同一条边内部的共线点去掉，
起点取最左下点、顶点按逆时针排列；最近点对枚举全部点对逐个求距离；直径在凸包
顶点上两两配对取最远；宽度在凸包每条边的朝向下把顶点投影取跨度、套最小值；
最大三角形枚举全部三元组；外接圆枚举点对与三元组、取能包住全部点且半径最小的
圆；包含判定逐条边卡有向面积；最小面积外接矩形枚举凸包每条边当朝向、逐个投影
求包围盒。规模小时直观可靠，结果一眼能看穿。

## 问题

朴素做法在规模一大就退化：凸包按点对逐个判定是立方量级，直径、最近点对、宽度
与外接圆都是平方量级，最大三角形是三重枚举。实现既没有把规模压下来的手段，
也没有任何计数能说明一条更聪明的做法到底省了多少，更与基线的事实无从对照，
两条路之间没有任何核验，退化情形也只能靠肉眼去猜。

## 目标

把 CalipersKit 从朴素几何扩成一套高效的凸包与卡壳工具集：凸包改成近线性构造；
直径、最小宽度、最小面积外接矩形改成旋转卡壳的近线性口径，在凸包上对踵推进；
最近点对另起一条按横坐标分治的独立路子，与卡壳路逐项一致且互不调用，两路再与
枚举全部点对的路子在小规模上逐项对齐；包含判定与最小面积外接矩形各接一个独立
能力并与独立口径一致；新老两路对同一批点集的事实逐项一致，并暴露枚举点对数与
卡壳推进次数的规模差距；覆盖空点集、单点、两点、全部共线、重复点、凸包退化成
线段、三点共线、大整数与负坐标等边界；固定输入重复跑结果一致且不依赖模块级可变
状态；异常统一继承 CalipersErro 基类并快速失败；基线那条朴素路径一条都不许删。
