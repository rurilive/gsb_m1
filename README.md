# idmill

纯标准库的 id 生成小包，无外部依赖。

## 现状

idmill/counter.py 提供最简单的进程内自增计数器 Counter：

- next_id：返回当前值并把计数器加一，第一次返回 start（缺省 0）
- value：下一个将要发出的值
- idmill/__init__.py 只导出 Counter

没有时间位，没有工作节点位，没有序列位，没有时钟回拨处理，没有解析能力，
也没有工作节点分配与并发生成的概念。

## 目标（见任务描述）

把 idmill 从朴素自增改成分布式唯一 id 生成器：id 由时间戳位、工作节点位、
序列位拼成，位宽可配；能用解析函数从 id 还原三部分并与生成时一致；同一毫秒
内多生成按序列递增、序列用尽则等下一毫秒，整体单调不重复；检测到时钟回拨要
按明确策略处理且处理期间仍单调不重复，不许直接抛错崩掉；多个生成器实例的
工作节点位互不相同、位宽内重复分配要 fail fast；多线程同实例并发要全体唯一；
位宽超限与非法工作节点号要 fail fast。全部仍在 idmill 里，纯标准库，用注入
时钟与可配位宽，异常继承 IdError 基类。约束：

- 现有行为与 tests/test_counter.py 基线保持一致（基线一个字不改）
- 新行为另开 tests/test_idgen.py，用注入时钟与固定序列断言
- 纯标准库，不引第三方，测试不许依赖真实时间流逝

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests -v
```
