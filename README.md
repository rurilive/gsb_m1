# matchingx

一个只用 Python 标准库的二分匹配小工具。包内模块 pair.py 提供 BrutePair 类，
维护一张二分图：左侧一组点、右侧一组点，边用对集合表示。add_edge 逐条加边，
is_perfect 判断是否存在覆盖全部左侧点的完美匹配，max_pairs 求最大匹配条数，
matched_to 在某个已求出的匹配里返回左侧点配到的右侧点。

## 现状

BrutePair 的求匹配一律靠回溯枚举：从第一个左侧点开始，逐个点尝试配到一个尚未
被占用的右侧点，同时也允许不配，从而把所有匹配组合都走一遍，取其中条数最多的
作为最大匹配，再用它判断完美匹配与回答 matched_to。规模小时直观可靠。

## 问题

回溯枚举的搜索量随点数指数增长，边一多、点一多就迅速撑不住。当前实现既没有
任何增广的观念，也没有把搜索量量出来的手段，无法说明一条更聪明的做法到底省了
多少，更谈不上在图上导出点覆盖、独立集这类与匹配紧密相关的结构。

## 目标

把 BrutePair 从回溯枚举扩成以增广路为核心的二分匹配工具：用轮流找增广路的做法
求最大匹配条数，与回溯枚举结果逐项一致；给出一个具体的最大匹配方案并逐项断言；
完美匹配判定改为最大匹配是否覆盖全部左侧点；暴露增广提交次数与访问边数，用计数
量出与回溯搜索量的差距；由最大匹配导出最小点覆盖，并断言其大小等于最大匹配数；
再由最小点覆盖导出最大独立集，断言大小等于点数减最小点覆盖；同一张图反复求匹配
结果稳定；覆盖空图、单点、无边、完全二分图、一侧为空、重复加边、孤立点等边界；
固定图与固定增广顺序重复跑两次结果完全一致；异常统一继承基类并快速失败。
