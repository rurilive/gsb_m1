# seqx

一个只用 Python 标准库的小仓库，提供序列上的区间操作工具集。

## 现状

- 包名 `seqx`，核心类 `Seq`，位于 `seqx/seq.py`。
- 内部只有一份平铺的 list，元素按构造给出的顺序保存，允许负数。
- `insert` 用切片把下标之后的一整段整体后移，`delete` 把之后的一整段前移。
- `reverse(left, right)` 用切片取出区间、逆序之后再拼回原位。
- `add(left, right, delta)` 用循环对区间内的每个元素逐个改写。
- `sum` / `min` / `max` 逐元素遍历区间，空区间分别返回 0 或抛 `EmptySequenceError`。
- `get` / `set` 按下标读改，越界抛 `IndexOutOfRangeError`。
- `replay(values, operations)` 依次回放一串操作，返回末态与逐步返回值。
- 所有自定义异常继承自 `SeqError`。

## 问题

每次中间插入或者删除都要搬动一整个数组；区间翻转靠切片复制再拼回，
区间加逐个改写，区间统计从头累一遍。规模一上来，每次局部改动的代价
就随区间长度或者元素个数线性上涨，中间没有任何层级结构可供复用。

## 目标

把核心从平铺列表换成以平衡树为核心的序列工具集：用平衡二叉树按位置
组织序列，节点维护子树大小以按下标定位；支持按下标插入与删除；支持
区间翻转与区间加，用懒标记标记待处理区间、下推时再落实；支持区间求和
与区间最值，靠子树统计量合并；支持按下标查询单点值。改造后中序还原出
的序列必须与直接操作列表所得逐项一致，新老两条路径对同一批操作给出的
事实必须对得上，原先那套朴素列表操作保留下来做对照。
