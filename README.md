# sketchly

频次计数小库，纯标准库，无外部依赖。调用方喂进一串键，想知道每个键
大概出现了多少次，要求内存只随配置的计数器规模固定，不随键的种类数
增长。

## 现状

- `sketchly/counter.py`：`ExactCounter`，一套全量精确计数。`add(key)` 把
  一个键的次数加一，`add(key, amount)` 加指定的非负整数次，`add_many(keys)`
  逐个加入，`value(key)` 给出某个键的精确次数，`total()` 给出全部键的次数
  之和，`keys()` 列出记过的键，`merge(other)` 把另一个计数字典逐键精确加
  进来，`reset()` 回到初态。

键原样存在一个字典里，每个键对应一个精确次数。计数精确，但字典会随
键的种类一直涨，键空间一大内存无界；没有固定大小的计数器数组，没有
哈希定位与最小值估算，没有单侧误差与误差界，不能把两个结构并起来估
合计频，更没有减除与区间查询。
