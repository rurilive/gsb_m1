# regexlib

一个从字面匹配起步的规则匹配小库，只用 Python 标准库，没有任何外部依赖。

## 现状

包内只有一个模块 `regexlib/pattern.py`，核心类叫 `LiteralPat`。它是改造前的基线实现，
只认不含特殊字符的字面串：

- `match(text)`：`text` 整个等于模式才算命中。
- `search(text)`：`text` 里含有模式这段子串就算命中。
- `finditer(text)`：返回模式作为子串出现的全部位置，非重叠口径。
- 一旦模式里出现星号、问号、加号、竖线、圆括号、方括号、点号、脱字符、美元号或反斜杠，
  就抛出 `RegexError`（`ValueError` 的子类），说明当前只支持字面匹配。

它完全没有规则匹配能力，既没有状态与转移，也没有闭包与选择。

## 问题

真实场景里的模式不只是字面串，需要字符、连接、选择、星闭包、加闭包、问号可选这些基本构造。
基线只能做相等与包含判断，既无法描述可变长度的模式，也无法把模式编译成可复用的状态机。

## 目标

把 `LiteralPat` 从字面匹配扩成以非确定有限自动机为核心的规则匹配工具：

- 支持字符、连接、选择（竖线）、星闭包、加闭包、问号可选，`match` 整串匹配、`search` 子串匹配。
- 把模式编译成状态与转移，并暴露可读的状态数与转移数。
- 对固定模式与固定输入，非确定自动机与确定化后的自动机给出相同结果。
- 正确处理空串与空替代，星闭包可匹配零次。
- `finditer` 返回全部匹配位置，重叠口径写清并断言。
- 匹配走过的步骤数与输入长度成线性关系，不随回溯爆炸。
- 空模式、只含空串的模式、无效模式、空输入都要有明确行为；非法模式 fail fast。
- 异常统一继承 `RegexError` 基类。

## 约束

- `tests/test_pattern.py` 是基线测试，一字不许改，且必须继续全绿。
- 新行为另开 `tests/test_dfa.py`，用固定模式与逐字断言。
- 只用标准库，不依赖标准库的正则模块。
- `demo.py` 第二段补一轮非确定自动机匹配与确定化对比演示。
- README 末尾补一段实现说明，讲清构造语法与自动机口径。
