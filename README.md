# hanoi

汉诺塔递归结构工具的朴素实现，纯标准库，无外部依赖。

## 现状

hanoi/core.py 只有一条路：递归生成完整的移动序列，再在序列上做统计与校验。

- move_count(n)：n 层塔的最少移动步数，用循环累加
- generate_moves(n)：递归生成完整移动序列，每步是 (盘号, 起始柱, 目标柱)
- step_moves(n)：把完整序列切成 (起始柱, 目标柱) 二元组
- min_moves_to(n, target)：把整座塔搬到指定柱的最少步数
- kth_move(n, k)：第 k 步的移动，先造出整个序列再取第 k 项
- is_valid_sequence(n, moves)：逐步重放，判断给定序列是否合法
- hanoi4(n)：四柱汉诺塔最少步数，经典递推逐层试取最小
- min_moves_restricted(n)：限定规则变体，用最直白的最短路径搜索

内部无论求第几步、还是校验序列，都先把整条移动序列算出来。序列长度按二的
n 次方减一增长，n 稍大时间与内存就顶不住；四柱与限定规则各写一份，彼此不
共用口径。

## 问题

任何一项能力都要先生成全部移动，n 到二三十，序列长度已是上亿条，时间与内存
都被拖垮；求第 k 步本可直接定位，却被整段生成包住；校验序列只能逐步重放，
无法一眼看出合法性；四柱、限定规则变体的结果没有独立口径可互相印证。
